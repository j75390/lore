# LORE (공개 화면)

https://lorechat.kro.kr — 오리지널 AI 캐릭터와 대화하는 서비스 LORE의 공개 화면입니다.

- 화면은 GitHub Pages에서, AI 모델과 대화 기록은 운영자 PC의 서버(persona-chat-server)에서 돌아갑니다.
- `api.json`에 지금 켜진 서버 주소가 적힙니다. PC가 꺼져 있으면 화면이 "서버가 쉬는 중" 모드로 뜨고, 캐릭터 구경(`characters.json` 사본)만 됩니다.
- 이 저장소는 `scripts/publish_web.py`가 만들어 올립니다. 직접 고치지 마세요.
